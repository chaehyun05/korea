# 한능검 심화 연습장

한국사능력검정시험 **심화 51~80회(1,500문항)** 기출과 **예상문제 46개**를 풀고, 문항별 상세 해설과 연상 암기를 볼 수 있는 정적 웹사이트입니다.

## 기능
- 회차 · 시대 · 문항 수 · 섞기를 골라 문제 풀기
- 문제마다 정답 근거, 선지별 해설, 더 알아둘 것, 연상 암기
- 오답 노트: 브라우저(localStorage)에 저장되며, 다시 풀 수 있음
- 20문항 이상 풀면 '완료' → 예상 점수와 약한 시대, 암기 카드(PNG/PDF 저장)
- 공부하기: 시대별 연상 암기와 기출 속 문화유산 모음

## 실행
`fetch`로 JSON을 불러오므로 파일을 더블클릭하면 동작하지 않습니다. 웹 서버로 열어 주세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## GitHub Pages 배포
1. 이 폴더의 내용을 저장소 루트에 올립니다.
2. Settings → Pages → Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/`에서 열립니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체(HTML·CSS·JS) |
| `data.json` | 회차별 정답 · 배점 · 시대 · 해설 |
| `img/rNN.json` | 회차별 문항 이미지(WebP, base64) |
| `mnemonic.json` | 시대별 연상 암기 |
| `yesang.json` | 예상문제 |

## 참고
- 76~80회 정답은 공식 정답이 공개되기 전에 직접 풀어 정한 것이며, 화면에 '자체 정답'으로 표시됩니다.
- 기출 문제 이미지의 저작권은 국사편찬위원회에 있습니다. 공개 저장소로 배포할 때는 이용 조건을 확인하세요.
